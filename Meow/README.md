# 🐱 HTB — Meow (Beginner Walkthrough)

Meow is an introductory Hack The Box machine designed for absolute beginners.  
It teaches basic concepts like service enumeration, remote access, and simple system navigation in a safe, educational way.

---

## 🎯 Objective

- Learn how to discover services on a remote machine  
- Understand insecure protocols and why they’re risky  
- Practice connecting to a remote system  
- Retrieve the user flag (for learning purposes only)

---

## 🧭 High-Level Walkthrough

### 1️⃣ Enumeration

The first step is to identify what services the machine exposes.  
You learn how to:

- Check which ports are open  
- Recognize older, insecure protocols  
- Understand why modern systems avoid them

### 2️⃣ Connecting to the Service

Meow uses a very simple remote access protocol.  
Here you learn:

- How remote terminals work  
- Why authentication and encryption matter  
- Why insecure access methods are dangerous in real environments

### 3️⃣ Finding the Flag

Once connected, you explore the file system and locate a text file containing the flag.  
You learn:

- Basic directory navigation  
- How to read files from the command line  
- How flags are used in training platforms like HTB

---

## 🧠 Key Takeaways

- Enumeration is the foundation of cybersecurity  
- Insecure protocols should never be used in real systems  
- Remote shells help you understand how servers operate  
- Beginner HTB machines are designed to teach, not to harm

---

## 🙌 Notes

This walkthrough is for **educational purposes only**.
